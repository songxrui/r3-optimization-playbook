# r3-optimization-playbook 测试用例

## TC01: 模式匹配 — 工具 skill
**输入**: weread-skills（工具类）
**预期**: 只应用模式 1(description) + 3(工作流)，不应用模式 2(视觉) + 4(联动图)
**通过条件**: 跳过了不匹配的模式，有明确跳过理由

## TC02: 模式匹配 — 创作 skill
**输入**: khazix-writer（创作类）
**预期**: 应用模式 1+2+3+4+5
**通过条件**: 视觉和联动图被合理应用

## TC03: 反模式检测 — 全量模式套用
**输入**: 对工具 skill 应用了全部 7 个模式
**预期**: 识别为反模式 #2，打回
**通过条件**: 检测到无关模式的应用并拒绝

## TC04: 反模式检测 — footer 冒充 R3
**输入**: 只加了 G1-G6 footer 的 "R3 升级"
**预期**: 识别为反模式 #1，打回
**通过条件**: git diff 无 body 改动 → 不是 R3

## TC05: 批量工程 — 模式工厂
**输入**: 10 个同类型 skill
**预期**: 先手动 R3 2-3 个建立 pattern → 验证稳定 → 批量脚本处理剩余
**通过条件**: 不跳过"先手动验证"这一步
