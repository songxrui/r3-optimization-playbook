# EXAMPLE_01: r3-optimization-playbook 实战 — 用模式3"Phase工作流锻造"升级 dbs-learning

## 输入
```
skill: dbs-learning (STUB, 456B)
目标: 用 playbook 中的模式升级到 RICH
```

## 应用的模式

### 模式 1: Description 锻造
- 提炼核心定义: "交互式学习系统"
- 生成 6 个触发词: dbs-learning、怎么学、系统学、课题学习、循序渐进、交互学习
- 添加正反例各 2

### 模式 3: Phase 工作流锻造
```
Phase 1: 课题拆分 — 按难度/深度/分支拆成连续模块
Phase 2: 首篇产出 — 从最基础模块开始写
Phase 3: 反馈收集 — 用户对上一篇的理解反馈
Phase 4: 深度调整 — 基于反馈调整下一篇的难度/侧重点
Phase 5: 循环 — Phase 3-4 循环直到课题完成
```

### 模式 5: 失败兜底锻造
| 失败场景 | 处理 |
|---------|------|
| 用户中途中断 | 保存当前进度，标注"未完成" |
| 用户反馈"太简单" | 提升下一模块难度 |
| 用户反馈"听不懂" | 降低下一模块难度，增加前置概念 |
| 课题太大，模块过多 | 建议拆分课题或提高粒度 |

## 升级结果
- 优化前: 456B (无 Phase, description 残缺)
- 优化后: 约 5KB (5 Phase + 完整 description + 4 种兜底)
- 应用模式: 模式 1 + 模式 3 + 模式 5

## 验证
- ✅ 3 个模式均有效应用
- ✅ 未应用的模式（如 4:视觉锻造）合理跳过（文字 skill 不需要）
- ✅ 最终产品达到 RICH 级别
